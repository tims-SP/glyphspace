# 字间 · GlyphSpace

**新世纪五笔06版交互式学习网页**：以字根空间记忆、动态拆字、逐键聚焦和低认知负担的沉浸练习为设计方向。

- **[V0.36键盘交互原型](./preview/v0.36/index.html)** — 第40轮渐进键盘、物理布局与焦点连续性原型；**不是完整学习功能**。

两个页面均为独立HTML，无需依赖安装或打包。GitHub Pages启用后首页与预览路径分别为 `/` 和 `/preview/v0.36/`。

## 产品方向

**空间**：固定字根与物理键位映射，避免视觉位置漂移。

**渐进**：当前汉字→拆字步骤→焦点键→焦点字根；移动端使用字母键帽、独立字根放大分页。

**专注**：桌面/手机主流程目标为全屏零主体滚动，把设置和校准收纳到二级界面；必须同时满足真实设备可达与无障碍。

**可信**：来源证据与渲染数据分离。字体路径、旧SVG、图像相似度和哈希不等于原始字根身份认证。
