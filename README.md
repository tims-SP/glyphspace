# 字间 · GlyphSpace

新世纪五笔06版交互式学习网页：字根空间记忆、逐键练习和交互式键盘。

## 浏览网页

- **稳定学习网页**：打开仓库根目录的 [`index.html`](./index.html)。
- **V0.36 实验预览**：打开 [`preview/v0.36/index.html`](./preview/v0.36/index.html)。

两者均为单文件HTML，无须安装依赖或构建。可直接下载后使用浏览器打开。

## 版本说明

- `index.html`：保留原封不动的 **V0.35冻结正式HTML**。网页内部标题可能仍显示 V0.34；请以文件SHA与项目记录为准，不要通过改标题破坏冻结哈希。
- `preview/v0.36/index.html`：第40轮T03/T05 **隔离交互原型**，不是完整学习功能的V0.36正式替代版。
- 第45轮为证据审计进展，未发布更晚的整合版学习入口。

见 [`docs/STATUS.md`](./docs/STATUS.md) 与 [`docs/SHA256SUMS.txt`](./docs/SHA256SUMS.txt)。

## GitHub Pages

创建仓库后：Settings → Pages → Deploy from a branch → `main` / `(root)`。
首页展示稳定版，试验页面路径为 `/preview/v0.36/`。私有仓库的Pages可用性取决于GitHub账号和套餐。
