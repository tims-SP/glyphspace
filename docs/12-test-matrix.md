# 12 · 可执行验收矩阵与真实环境门槛

> 来源：[V0.36-P0原始规划](./history/V0.36-P0-original.md)中Gate A–D、GEO/DATA/REF/INPUT/UI/DIST测试表。这里是**测试用例规范**，不是声称这些测试已执行。静态仓库验证可运行`python3 scripts/verify_repo.py`，不能替代下列集成/真机测试。

## Gate A：数据/迁移（T00–T04）

| 测试 | 动作 | 通过条件 |
|---|---|---|
| BASE-01 | SHA检查正式HTML、旧SVG及176条训练编码 | 基线原样，可恢复 |
| DATA-01 | 用隔离存储导入V0.35 v15/v16旧坐标、人工审阅信息 | 有效用户手调位置与审核归属不丢失 |
| DATA-02 | 坏JSON、缺字段、版本冲突、部分写入、中断及重入 | 错配0、冲突隔离、可回滚，旧值不被覆盖 |
| DATA-03 | 修改Path、参考图来源或几何 | 仅对应的五维复核过期，不沿用伪认证 |
| ID-01 | 插入/删除/重排M键微变体 | 其余全部永久instanceId、默认几何、用户覆盖保持不变 |
| ORIGIN-01 | 真实共享原点双标签页并发，含/不含Web Locks | 锁互斥/并发冲突被处理，storage事件和恢复经过证据验证 |

**禁止**对真实用户localStorage做测试；Node FakeStore模拟与真实同源浏览器是两类证据。R46真实共享原点尝试被管理员阻断，状态=blocked而非pass。

## Gate B：原图/身份/补图（T01、T02、T05）

| 测试 | 动作 | 通过条件 |
|---|---|---|
| REF-01 | 每键逐张锁原始SHA与原图框，独立标注每个可辨形态 | 25/25键全枚举、有来源及父子层级、待确认数公开 |
| REF-02 | 核验M、Q/I/K/L/O/N/B/V等微形，排除标记、口诀、补码 | 类别合法，参考形态与视觉实例分离 |
| REF-03 | 原图新形态登记并生成独立Path/资产/实例 | 每个参考形态可单独选中/高亮/定位/复核 |
| REF-04 | K/E/B/V历史冲突及圆圈误框等负例 | 错误映射被阻断且完整留痕；不将拒绝数当缺根 |
| SEM-01 | root / variant / annotation / supplement / related覆盖测试 | 任何圈注/补码第二键不触发普通根的编码高亮 |

**认证必须来自同源原图逐笔确认与完整审图；** RGB/IoU/旧SVG/字体/审阅备注/截图只能支持有限断言。

## Gate C：SVG几何、轮廓与校准（T03、T06–T08）

| 测试 | 动作 | 通过条件 |
|---|---|---|
| GEO-01 | 变更视口/分辨率/缩放/DPR | 100×100归一局部几何和稳定ID不变 |
| GEO-02 | 在M键新增数个微型实例 | 原有位置不漂移、标签预留边界不侵犯 |
| GEO-03 | 删除或排序非输入变体 | 保留实例位置与编码规则不变 |
| GEO-04 | 任意字根hover、聚焦与输入反馈 | 不改永久坐标；未批准碰撞0 |
| GEO-05 | 完整键盘/拆字迷你键盘/单键视图 | 同instanceId、assetId、基础几何与方向 |
| GEO-06 | 用真实`inkBBox`、stroke轮廓及圈注/字母/区号检测 | 未批准碰撞和越界0，白名单均有人工原因 |
| CAL-01 | 新建参考对象、双视图/叠加、五维审核与资产版本变化 | 全周期闭环且签名改变自动失效 |

原始草案的**建议目标**：主根中心相对原图误差≤3/100单位，主根宽高误差≤10%；原图不可辨微根允许有证据的人工例外。此数是验收设计建议，**不是现状QA已通过的阈值**。

## 报告最小字段

每项记录 `testId / layer / sourceRevision / environment / actions / expected / observed / result(pass/fail/blocked/not-run) / evidenceFiles / operator / measuredAt`。如未实测，必须是`not-run`；管理员禁止导航为`blocked`。截图静态检查不得提升为`source-certified`。

## 仓库当前可运行的静态门禁

`python3 scripts/verify_repo.py`：只验证仓库两份HTML哈希、文档与任务账本一致性、25键计数、SHA256清单、相对文档链接及必要文件，**不声明**在真实设备、同源存储或逐笔认证方面通过。
