# 14 · 并行UI重构与原始任务编号的调和

> 纠错来源：原始 [V0.36-P0任务规划](./history/V0.36-P0-original.md) 明确 **T03=SVG坐标内核、T05=字根完整性补图**。2026年10月的第36–40轮隔离键盘原型曾以「T03/T05」标注UI工作，属于**编号漂移**而非原始任务定义变更。

## 两条工作流

**Root track（R）：** T00–T11按原始定义执行，不因新UI需求更名、移位或取消；阻塞任务必须保持待验。

**UI track（UI-01–UI-05）：** 新增的视口零滚动、移动端字母帽、聚焦字根分页、折叠迷你键盘和键盘无障碍工作，与Root track并行验证。早期在原型文件内写过的旧T03/T05标签仍可作为**历史标记**，但最新文件/任务引用必须改用UI编号。

## 时间和范围关系

- **V0.34**：单HTML全屏、二级页面减法、主体零滚动、折叠mini键盘已经有一定模拟视口回归；系统软键盘和真机仍需独立检查。
- **V0.36-P0原始字根重构计划**：规定保留V0.34主布局，不在字根重构内新做一轮主页面信息架构；其核心为来源资产与几何、语义、迁移。
- **第36–40轮新增UI实验**：在用户后续设计要求下探索渐进键帽与移动端焦点放大等；独立原型有测试，但未合并正式训练闭环。
- **当前协议**：后来的UI目标在单独UI track规划，不再解释为对原始T03/T05工作包的重定义。两条工作流可共享字段与视图，但不可互相冒称验收。

## 串联与发布依赖

- UI-02/03的字根身份引用必须使用T02认可的`instanceId`，默认几何来自T03，不可以由两个页面独立硬编码造成漂移。
- UI-04的盲打提示必须由T09训练状态机控制；系统输入键盘不会让未输入答案泄漏。
- UI-05（焦点和读屏）需进入T10的真实设备可访问性验收证据。
- UI-track任何交互截图通过，都不能代替T01字根认证、T05补图、T06轮廓复核、T07碰撞、T08审阅流程或T11发布。

## 正式的ADR变更规则

如将来确实希望**修改T编号定义**，必须提出独立ADR并保留原表，列出迁移表和每个旧引用的语义；未确认前应沿用历史编号，不能悄悄覆盖。
