## 验收分级

### A. 数据与完整性门槛（阻断发布）

1. 25/25正式根键和Z键正确；每张参考键帽中所有可辨形态建立referenceShapeId。
2. 每键记录：参考图可辨数、已映射数、缺失数、不可辨数、5维认证数。不可辨须保留来源局部证据而不是忽略。
3. 缺失独立形态=0、类别错挂=0、无法绘制SVG=0、错误将补码第二键当普通字根=0。
4. 增删实例后所有既有ID保持稳定；个人坐标与审核状态能安全迁移。

### B. 字形与位置门槛（逐键审核）

1. 一个原图形态对一个可操作实例；同一根的多个视觉变体共用取码含义，但各自可调位。
2. 逐笔确认笔形/方向/缺笔；整字替代不合格，除非判定形态完全一致。
3. 建议坐标基线：主根中心与归一原图差≤3/100、主根宽高差≤10%；微根受原图清晰度约束，以人工放大复核为最终标准。该阈值为建议验收值而非已达成。
4. 对实际渲染bbox、笔画、注释、字母与区号进行碰撞；未审批交叠0，焦点放大也保持。
5. 单键放大/完整/迷你键帽使用相同路径资产和原始几何；不允许靠CSS自动换行。

### C. 自动回归门槛

1. 静态：schema + 字根编码+关键类目校验；漏图/孤儿Path/重复ID/无许可证=0。
2. 几何：普通/高亮/降权三状态、25键全扫；DPR1/2/3和典型尺寸截图差异。
3. 交互：引导/进阶/盲打切换；重复码/末笔识别码15种/补码PY、PU、QT；错误按键不推进。
4. 数据：历史v15/v16坐标及复核记录迁移；加入新实例后旧键位不变。
5. 布局：320x568、390x844、844x390、1440x900等，加真机iOS Safari/Android Chrome；典型屏可见区域零横纵滚动。
6. 无网络、无外部字体包依赖；打开HTML后完整练习可运行。

### D. 实机与主观视觉门槛

1. 25键逐键对照放大图；执行者勾选“形状、完整、位置、比例、语义”五维。
2. 典型桌面、手机横竖屏当前目标根可辨；极窄屏采用焦点放大/分区触控兜底，不能谎称全部微根都在35px键帽上可辨。
3. 各模式输入响应、虚拟系统键盘弹出、安全区和高对比度/减少动态设置不遮挡关键操作。

## 最合理实施顺序

1. **建立原图参考形态台账**：先确定目标总量，解决漏项与归类。
2. **补齐M/Q/I等高风险键的微型独立SVG**：每个候选建立稳定ID。
3. **统一视觉体系**：逐项修复错误字形、光学重量、笔画方向；不是简单换字体。
4. **精校25键坐标**：图中归一对照，先主根后微根，含焦点和圈注。
5. **迁移存储与人工审核机制**：将历史索引映射为instanceId并保留自定义配置。
6. **自动回归+手机真机验收**：公布通过数/待审数，完成后才允许称“原图逐项复核完成”。
