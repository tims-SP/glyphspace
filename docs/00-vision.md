# 00 · 产品愿景与边界

> 状态：**产品方向已确定**；本文描述目标，不等于所有功能已经实现。更新时间：2026-10-22。

## 一句话定位

**字间（GlyphSpace）** 是以「新世纪五笔06版」为核心的本地优先、可离线使用的交互式学习网页：通过字根的**固定空间位置**、逐键聚焦与动态拆字，把记忆键位、识别字根和实际输入结合为一次连续体验。

名称「字间」兼有字与字之间、字形内部空间的含义；英文 GlyphSpace 为项目名，不意味着已经开发其他汉字输入法。

## 用户目标

1. 初学者：从五笔键位、字根、拆字规则到打出汉字，不必来回查询纸质字根表。
2. 复习者：看到汉字即能判断拆分与编码；错误能定位到具体键位与字根。
3. 桌面及移动用户：训练区、必要辅助信息和键盘始终位于**可视区域**，正常训练路径不依赖页面滚动。
4. 视障及键盘用户：具备可用的语义结构、可操作焦点与状态反馈；需要真实读屏验收，不能以静态ARIA检查替代。

## 核心体验闭环

**呈现目标汉字 → 动态显示拆分线索 → 高亮当前步骤与对应键位/字根 → 用户输入 → 即时反馈 → 继续下一步或重试。**

用户的注意力应首先落在「正在打的字」，其次是「正在输入哪一步」，最后才是「必要时查看的辅助资料」。训练不以一次性展示所有资料为目标。

## 设计不变项

- **06版规则为准**：不随意混入86版或其他输入方案。
- **空间记忆优先**：真实物理键位和字根相对布局长期稳定；缩放不应改变身份。
- **本地优先**：正式学习无需账号和后端；不把远程服务当作核心依赖。
- **渐进披露**：当前任务强相关的信息优先，不把所有字根挤进移动键帽。
- **证据可追溯**：字形、位置、对应关系均需要来源和认证状态。
- **兼容与可逆**：冻结基线不可改；新方案独立验证后再迁移，具备回滚路径。

## 成功的判定

不是「增加了多少功能」或「截图多像参考图」，而是：

- 用户在桌面和移动端无须滚动即可完成主要训练任务。
- 高亮的键位和字根与实际编码一致，所有输入反馈有可解释的来源。
- 25键均经逐项字根认证；未确认的候选不进入正式认证数据集。
- 旧版本保存的数据可迁移、可回滚，且不碰触用户真实存储进行实验。
- 在真实浏览器、多标签页、真实键盘、移动软键盘和读屏环境完成必要验收。

## 非目标 / 未决

- 当前**不**把React、Vue、Svelte等框架重写定为既定任务；先判断原生单HTML是否仍满足需求。
- 不构建账户系统、云同步、服务端推荐、排行榜或大规模社交功能。
- 汉字结构教学、其他输入法与更大型平台化能力只属于**可能演化方向**，不占用V0.36准入范围。
- 不以旧SVG复用、字体字形、裁片哈希或图像相似指标推定原图字根认证。
