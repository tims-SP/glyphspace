# 07 · 验收规范与质量闸门

> **定义**：「测试通过」仅说明测试覆盖的那个断言成立，不代表项目整体完成；「正式字根认证」必须另有独立证据。此规范是准入条件，不是声明现状已通过。

## 一、完成状态必须分级

| 状态 | 最小含义 |
|---|---|
| Planned | 任务定义和验收准则存在 |
| Prototype | 仅实验分支或独立HTML实现 |
| QA-passed | 自动化或人工测试通过，并说明环境及覆盖范围 |
| Source-reviewed | 来源及身份已完成人工逐笔证据复核 |
| Integrated | 接入正式候选、与真实规则及状态相通 |
| Accepted | 全部约束和真实环境QA通过；可追溯到代码/证据/回滚 |

**不允许**根据 `QA-passed` 自动宣布 `Source-reviewed`，也不允许根据 `Integrated` 自动宣布 `Accepted`。

## 二、不可修改基线

- 冻结V0.35 HTML SHA256：`fd7b9bdada44ab2d7452d71f99e77cfd7a7fe82eb9b29e3f0b41ab32fb758ddc`。
- 2008参考图 SHA256：`df5eb1a8678eea5ae27b3bfbc6bcef17af8b8ef558696834214dcdffa86dcd49`。
- 176条旧训练编码、已冻结SVG、旧用户存储内容均不得被未授权或实验性流程修改。

每次发布候选必须独立复算SHA，验证受保护实体数量、键位映射和禁改差异清单。

## 四、分层验证清单

### 资料与字形

- [ ] 参考原始字节具有来源、许可和SHA；Pillow或等价解码获得尺寸/颜色/无损裁片。
- [ ] 父证据、圈注、空白误框与真实叶明确区分；K:2/K:3、E:1/E:8等冲突解决。
- [ ] 25键每个视觉字根的笔画、身份、键位、旧路径绑定经人工逐项确认。
- [ ] 由审核者分别签署身份复核和整键覆盖复核；确认缺根数量。
- [ ] 高亮、键位、训练步骤与正式编码规则逐项比对。

### 行为与响应式

- [ ] 完整练习闭环：正确、错误、退格、重试、连续切换及所有训练模式。
- [ ] 桌面/手机竖横屏、最窄/矮视口与浏览器200%缩放下主控可达、无非预期主体滚动。
- [ ] 软键盘打开/关闭、页面焦点中断后恢复正确。
- [ ] 完整/折叠/mini键盘和当前字根分页状态同步。
- [ ] 键盘导航、可见焦点、信息播报，真实VoiceOver/TalkBack/NVDA等环境通过。

### 存储、安全与发布

- [ ] 在独立浏览器配置中测试真实共享原点多标签页并发、Web Locks可用/缺失、storage事件、冲突回滚。
- [ ] 旧坐标/设置/人审数据只读预检、迁移备份、异常值拒绝与版本降级。
- [ ] 离线运行、禁止未声明网络依赖，检查HTML/脚本内容安全及第三方许可证。
- [ ] 正式候选与原V0.35可并行存在，并有完整回退指令。
- [ ] 审计归档、QA日志、原图证据、逐文件SHA和独立解压复验可复查。

## 五、当前已验证内容不是什么

第45轮22/22独立QA、20/20 Chromium原图预览、第44轮23/23、第43轮20/20、第42轮28/28、第32轮Node26/26，只支持**相应隔离测试断言**。Chromium中以 `about:blank` 嵌图查看原始证据，不等于真实共享原点、正式训练集成、读屏或字根认证。

第45轮ZIP共663文件且独立解压663/663 SHA一致，只说明**该ZIP与所见继承文件校验一致**；第10–12轮和第35轮ZIP缺失，不能称完整连续历史。

## 六、每轮交付定义

必须保留：上一轮实际可得的完整包、父包/新增文件清单、逐文件SHA、独立工具QA、真实浏览器QA（若执行，应报实际环境）、报告、独立累积ZIP、再次解压后独立复核记录。任一环节失败应注明未完成，不能用说明性文字代替文件。

## 七、发布否决条件

有任一条件即阻止宣称完成：25键未正式认证；实际缺根仍未知而渲染为完整；冻结实体或176编码被更改；真实用户存储遭实验性改写；任务T00–T11存在未验收项；存在无法触达的训练控件；重要来源/测试数据无法复现。
