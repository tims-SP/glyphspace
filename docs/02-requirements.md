# 02 · 功能与非功能需求

> 定义：`[基线]`为冻结V0.35含有对应功能，`[隔离UI]`为第36–40轮独立键盘演示，`[计划]`为原始V0.36-P0待开发工作，`[待验]`为无正式完整QA。两条工作流不得合并编号。详情：[11追踪台账](./11-traceability.md)。

## 用户学习闭环

* **F01 [基线]** 随机/按既定规则呈现练习汉字，显示编码、输入进度与正确/错误反馈。
* **F02 [基线]** 新世纪五笔06版取码：176训练样本、15种末笔字型识别码、PY/PU/QT三种补码、键名字与成字字根专门规则；不得偷偷修改。
* **F03 [基线]** 引导/进阶/盲打三模式、错误不推进、三码空格确认、实体键盘/触屏/系统输入法；盲打尚未输入提示不得泄露。
* **F04 [基线+计划]** 目标汉字 → 动态拆字 → 当前步骤 → 焦点键与焦点字根，状态必须唯一且跨视图同步。

## 原始字根系统（Root track）

* **R01/T01 [计划]** 原图25键穷尽清点、每形态独立source ID、父图/圈注/补码/口诀分类。
* **R02/T02 [草案]** 六类实体与永久实例ID，`root/variant/annotation/supplement/related`精确区分、旧序号映射。
* **R03/T03 [计划]** SVG内核固定键帽`100×100 viewBox`，真实`inkBBox`、锚点、光学偏移和独立label预留区；三视图同源，插入实例不位移。
* **R04/T04 [隔离实验]** 版本化旧设置迁移，必须保留有效用户手调，错误配置隔离、可逆回滚；真实多标签事务待测。
* **R05/T05 [计划]** 先M后Q/I/K/L/O/N/B/V等补齐真实可辨独立SVG实例；未经认证不能强行宣称新增缺根数。
* **R06/T06–T08 [计划]** 轮廓逐笔一致、真实碰撞/光学定位及五维校准闭环。
* **R07/T09–T11 [计划]** 正式编码与三个键盘视图回归、真机和读屏验收、单HTML发行冻结。

## 并行交互重构（UI track）

* **UI-01 [V0.34基线；新UI待验]** 桌面/手机尽量全屏、主体零滚动、低认知负担；不可用`overflow:hidden`掩盖不可达控件。
* **UI-02 [隔离UI]** 标准QWERTY 25字根键物理位置；移动端字母键帽而非塞满微小字根。
* **UI-03 [隔离UI]** 当前键/当前字根明显聚焦，独立放大及分页；旧第36轮每页6项只是实验参数。
* **UI-04 [基线+隔离UI]** 完整键盘折叠时仍显示当前汉字的拆字迷你键盘，并保持盲打遮蔽。
* **UI-05 [隔离UI]** 可操作焦点、键盘导航、真实屏幕阅读器与软键盘兼容；Chromium about:blank模拟不是读屏通过。

## 非功能与发布边界

* **离线单HTML正式发布**，无运行时外部字体/CDN；用户可选校准参考资料必须与生产键帽独立。
* **冻结V0.35、旧SVG、176条编码及真实用户localStorage**；全部更改在独立原型或候选内进行。
* **来源可查且可合法分发**；不得将参考图裁片直接嵌入正式键帽渲染。
* **验收可复验**：自动测试、原图逐笔五维复核、全部25键、真实设备/输入法/读屏、存储回滚、完整发行档案。
* 非范围：账户/云同步、AI自动认证、无证据的缺根补图、强制框架迁移或未经审查公开第三方原件。
