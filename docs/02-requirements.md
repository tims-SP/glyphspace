# 02 · 功能需求与范围

## 学习训练

| 编号 | 要求 | 当前归属 | 验收要点 |
|---|---|---|---|
| F01 | 随机/顺序呈现目标汉字，展示输入进度 | [基线] | 正确码表关联、反馈与进度一致 |
| F02 | 新世纪五笔06编码及动态拆字步骤 | [基线] | 数据对照、例外规则、输入纠错 |
| F03 | 输入、退格、重试、下一题与键盘操作 | [基线] | 物理键盘、软键盘及焦点不丢失 |
| F04 | 当前步骤对应的键位及字根聚焦 | [基线]，重构[目标] | 由编码步骤驱动、视觉/语义同步 |
| F05 | 适度提示与辅助栏 | [基线]，减法[目标] | 聚焦优先、非焦点可按需展开 |
| F06 | 收起键盘后仍显示当前汉字的拆字迷你键盘 | [基线]有相关UI，重构[目标] | 不失去关键拆字信息 |
| F07 | 学习模式/设置/进度等辅助入口 | [基线] | 二级入口可发现、状态可回退 |

## 字根与键盘

| 编号 | 要求 | 当前归属 | 验收要点 |
|---|---|---|---|
| K01 | 25键物理布局与五笔分区对应 | [基线]/[原型] | 行列、映射及键位唯一性 |
| K02 | 字根相对位置来源可查、稳定 | [目标] | 键/实例/裁片/渲染/坐标各有独立ID |
| K03 | 偏旁部首不缺笔、不误形、不混同 | [目标] | 同源高清证据、逐笔复核；无缺根猜数 |
| K04 | 焦点键位突出，同键焦点字根更突出 | [原型] | 高亮状态、对比度及可访问性 |
| K05 | 移动端字母键帽+字根放大区、分页 | [原型] | 最窄视口触达全部字根 |
| K06 | 键盘折叠、焦点切换及导航恢复 | [原型] | 手动/自动焦点连续、退出安全 |
| K07 | SVG字根的可复用渲染与动态字体备用策略 | [基线]/[目标] | 无已认证来源不得升格正式 |

## 页面与兼容

| 编号 | 要求 | 当前归属 | 验收要点 |
|---|---|---|---|
| U01 | 桌面、移动、横竖屏尽量占满视口，不滚动主体 | [目标] | 多视口、系统缩放及软键盘真实验证 |
| U02 | 缩放与安全区、地址栏变高兼容 | [基线]部分实现 | 无遮挡、无无法触达控件 |
| U03 | 可见焦点、键盘导航、语义与读屏 | [原型]部分 | 真实读屏与键盘人工验收 |
| U04 | 全程离线可运行 | [基线] | 无网络亦能训练核心流程 |
| U05 | 保留旧设置、校准与人审数据或可逆迁移 | [目标] | 隔离FakeStore→浏览器事务→真实迁移 |
