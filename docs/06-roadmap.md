## 版本发布的最小标准

**未认证字根不作为已认证资产发布；迁移未得到真实共享原点验证不覆盖旧用户数据；页面无法用真实移动键盘/读屏完成训练不发布；T00–T11未全量真正验收不声明V0.36完成。**

## 更长期的演化（探索，不承诺）

1. 间隔复习、个性化弱项键位练习和诊断统计。
2. 汉字结构知识、图解拆字和进阶检索。
3. 若代码复杂度证明有必要，再考虑模块化构建与其他UI框架。
4. 可选离线安装（PWA等）只有在离线资源、缓存更新和生命周期可验收后才立项。

下一轮优先顺序按**阻塞风险**而非章节数量：证据认证 → 身份映射 → 真实存储事务 → 集成交互 → 真实设备验收 → 发布。
