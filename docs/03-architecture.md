# 03 · 技术架构：现状与拟演化

> **现状核对**：2026-10-22查阅仓库根目录 `index.html` 与 `preview/v0.36/index.html`。以下明确分为「已存在」「隔离验证」「拟议」，不把规划写成代码事实。

## 当前可运行结构（已存在）

```text
index.html   (V0.35 冻结、独立单HTML)
├─ HTML       练习区 / 帮助、设置、参考、键盘、辅助面板
├─ CSS        含桌面/移动布局及视口响应
└─ JavaScript
   ├─ 06编码与训练序列
   ├─ ROOTS / ROOT_COORDS / SVG字根渲染
   ├─ 当前字、步骤、高亮及输入反馈
   ├─ 拆字辅助与完整/折叠键盘
   ├─ 来源校准与人工审阅界面
   └─ localStorage中的设置/坐标/审阅数据
```

根目录 `index.html` 是V0.35冻结正式网页，SHA256见 [STATUS](./STATUS.md)。HTML内部标题显示V0.34，这是**页面内部名称与冻结交付标识不同**，不得只为了版本显示去修改冻结文件。

`preview/v0.36/index.html` 是第40轮继承的实验键盘：单独的焦点字根分页、物理行列、键盘折叠与键盘/焦点连续性测试代码。它没有承接完整V0.35训练闭环，不能直接替换根目录页面。

## 现状中的关键数据入口

| 实际存在 | 角色 | 注意 |
|---|---|---|
| `ROOTS`、`ROOT_COORDS` | 字根名称/绘制坐标 | 旧数组下标不能被误作永久字根身份 |
| `STROKE_VECTORS` 等SVG路径 | 可视化数据 | 旧路径不是官方原图认证结果 |
| 06版训练编码 | 题目及动态拆分基础 | 冻结176条编码，新增规则须回归 |
| `COORD_STORE`、`PRIOR_COORD_STORE` | 历史坐标补丁 | 有兼容/迁移遗留，禁止直接实验写入 |
| `STORE`、`REVIEW_STORE`、`CROP_STORE` 等 | 设置/人审/裁片存储 | 存量用户本地数据是受保护资产 |

## 拟议的V0.36分层结构（尚未正式拆分）

```text
训练界面 / 键盘界面 / 聚焦字根辅助视图 (View)
                      ↓
       交互状态机 / 学习进度 (Controller)
                      ↓
编码规则 ─ 字根稳定身份 ─ 数据来源账本 (Domain)
                      ↓
渲染资产选择 / 源图证据 / SVG路径 (Renderer/Evidence)
                      ↓
持久化适配器与版本化迁移 (Storage Adapter)
```

建议的职责边界：

- `training`：练习模式、当前汉字/编码、输入状态、纠错与进度。
- `wubi06`：06版字根/编码规则、只读源数据和规则回归。
- `root-catalog`：稳定ID、键位、可视/关联身份、审核状态。
- `keyboard`：物理行列布局、聚焦、折叠、辅助放大分页。
- `glyph-renderer`：根据有来源的资产输出SVG；对未认证资产提供明确降级。
- `storage`：用户资料版本化读取、隔离迁移、失败回滚。
- `audit`：来源追溯、验证报告和数据一致性检查；不得在正式渲染层悄悄更改源事实。

以上是**提议的模块边界**，不代表仓库中已出现 `src/` 目录、构建系统或框架运行时。

## 技术选择及框架评估

**当前仍用原生HTML/CSS/JavaScript**。原因：离线、无安装构建门槛、单文件可移植；目前最大障碍在字根身份、证据、响应式交互，并非框架本身。引入React/Vue/Svelte前需要证明其收益覆盖依赖、打包、迁移和维护成本。

未来若代码膨胀可先抽离纯数据与无DOM逻辑，再引入构建工具。无须为了重构而复制一套新的字根事实源。

## 状态与迁移原则

1. 正式界面只依赖已发布的只读数据与受控设置。
2. 审核工作台中的候选字根、人工意见、裁片框**不得直接提升成产品字根**。
3. 先用内存 `FakeStore` 和离线迁移演练确认schema，再验证真正共享原点的多标签页事务，再讨论读取/更新真实存储。
4. 迁移须校验旧键名及值域、记录版本、允许回滚；不依赖浏览器禁止用户访问旧数据。
5. 隔离审计默认不得写网络、文件外部资产或真实localStorage。

## 已知风险

- 新旧页面并未共享统一状态源，正式合并前存在映射漂移风险。
- 最窄移动端/软键盘可能使零滚动与大字根并存出现冲突。
- `localStorage` 非事务数据库，多标签页并发仍未获得**真实同源验证**。
- 小分辨率2008参考图无法通过放大恢复缺失笔画信息。
- HTML中的任何第三方字形/字体/图像分发需独立确认许可。
