# 机器可读任务和审阅数据

**唯一编号准则**：`T00–T11` 为 [V0.36-P0原始规划](../history/V0.36-P0-original.md) 中的字根重构任务。第36–40轮使用`T03/T05`字样的键盘UI实验是历史命名歧义，应在当前文档登记为 **UI-track**，不得覆盖原有T03 SVG坐标内核或T05补图任务。

- [t00-t11.json](./t00-t11.json)：12个原始工作包名称、依赖、原文验收条件及当前未验收状态。所有`accepted=false`并不否定已有隔离实验，只表示**没有整体正式验收**。

**编辑约束**：数组下标/旧槽位、稳定实例ID、参考图候选、SVG资产ID、语义root ID不能互相替代；不要自动填写疑似缺根；每次变更需更新来源、独立QA与[traceability](../11-traceability.md)证据列。

**文件检验**：从仓库根目录执行`python3 scripts/verify_repo.py`，该脚本验证编号、计数、冲突记录、校验和与Markdown本地链接，不涉及真实用户浏览器存储。
