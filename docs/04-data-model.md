# 04 · 字根数据、证据与身份规范

> **关键限制**：以下包括既存快照统计与拟议schema；稳定ID草案未正式集成，不能当成官方字根表的认证。

## 1. 不同的「数量」不可混同

依据第45轮审计包及此前基线（2026-10-22）：

| 数量 | 含义 | 解释 |
|---|---:|---|
| 25 | 字母键位 | 五笔字根键位；Z不是这25键之一 |
| 156 | V0.35记录总条数、T02稳定ID草案数 | 151条可视旧实例 + 5条关联记录 |
| 151 | 旧界面可视实例 | 不等于已认证不同字根数 |
| 115 | 与2008参考图的暂定采框对应 | 不是正式认证 |
| 36 | 尚未可靠对应的历史实例 | 不等于36个缺根 |
| 8/2/26 | 36条的历史失效/跨轮冲突/其他待核 | 第45轮K冲突属新增的跨层重复，不直接改这个分组 |
| 232 | 第6轮原图候选区域 | 222暂定叶 + 9父级证据 + 1否定空白锚点 |
| 0/25 | 正式完成字根认证的键位数 | **不能跳过这一闸门** |
| 176 | 既有训练编码 | 回归保护对象，不要与字根数量相加 |

## 3. 身份层（建议）

至少分开以下实体：

| 建议字段 | 含义 |
|---|---|
| `key` | 物理按键，如K |
| `legacy_slot` | 冻结旧页面的 `K:2` 等编号，仅作迁移键 |
| `stable_root_id` | 审阅中的长期字根身份ID，**草案状态** |
| `glyph_label` | 便于识别的字/部件标注，可能尚未定性 |
| `record_kind` | `visual` / `related` 等类别 |
| `reference_source_id` | 原始图片身份与来源版本 |
| `candidate_region_id` | 候选矩形的独立编号 |
| `bbox_px` | 原始图坐标，整数且须界内 |
| `crop_sha256` | 对指定解码方式与色彩模式下裁片字节求哈希 |
| `render_asset_id` | SVG路径/字体方案ID，不能代替字根ID |
| `audit_status` | 来源与身份核验状态，禁止默认为通过 |
| `review_record` | 复核人、时间、证据与反例 |

**注意：** 这些是将来结构化时的**建议字段**，不是现有正式数据库schema。

## 4. 证据状态（建议状态机）

```text
unreviewed
   ↓（找到来源）
source-bound
   ↓（完成逐笔复核与身份确认）
identity-reviewed
   ↓（完成完整键位与交叉排他性审核）
certified
   ↓（通过集成及回归）
released
```

从任何节点发现错误可进入 `rejected` / `blocked`，保留历史而不是静默覆盖。哈希一致仅支持「字节与来源未变」，不能自动跨越 `identity-reviewed` 或 `certified`。

## 5. 真实冲突（禁止强制合并）

- **E:1「舟」/E:8「用」**：历史暂用同一 `2008-E-vis-04`，第6轮确认为空白误框，关联**已否定**。
- **K:2「川」/K:3「丨」**：第45轮发现两者暂时引用 `2008-K-vis-03` 相同矩形 `(10,69,21,24)` 和相同RGB哈希。是**证据复用冲突**，不能推定字形相同。
- B:7「孑」及V:4「巛」存在跨轮暂定候选交叉，但没有已确认的旧SVG身份绑定。

## 6. 存储与迁移

V0.35可见键名包括：`wubi06-spatial-v2-settings`、`wubi06-root-coordinate-overrides-v16-svg`、`wubi06-root-coordinate-overrides-v15-svg`、`wubi06-root-coordinate-overrides-v03`、`wubi06-per-glyph-human-review-v05`、`wubi06-reference-crops-v06`、`wubi06-reference-profile-v06`。

迁移的最小顺序：建立旧key快照（在授权环境）→ 用版本化解析器验证 → `legacy_slot`映射草案 → 记录不可自动映射项 → 内存模拟冲突与中断 → 真实同源隔离验证 → 经许可迁移。任何实测不得写入用户日常浏览器profile。

## 7. 认证所需证据

同源高清原件字节、权利/版本来源、解码校验、逐字根人工笔画辨认、25键完整性、重叠/圈注剔除、映射排他性、第三方独立复核、完整回归。字体路径哈希、IoU、Canvas输出、拓扑、旧手工笔记都只是辅助证据。
