### 事实优先级

1. 冻结可复验源文件及其哈希；实际代码行为和可信原始参考；
2. 已附来源与QA的隔离分支报告、原图证据和提交记录；
3. 本目录经过复核的决策与设计约束；
4. 个人推测、草案、待核人工意见——**不得覆盖1–3**。

用户未来新确认的决定可通过更新决策记录改变设计方向，但不得悄悄篡改历史证据。文档和实现冲突时，请报告冲突，保留原始证据并开修复任务。
